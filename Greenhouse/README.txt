# 🛠️ GreenHouse 


The proposed project is a monitoring system for a greenhouse by providing sensor readings and according to those sensors certain actuators react
to ensure optimal growth environment.

https://github.com/zyadhany12/Greenhouse-Project

## 🎛️ Hardware Requirements
* **Microcontroller:** ATmega32 
* **Sensors/Actuators:** LM35 Sensor, Fan, Heater, WaterPump, Relay
* **Display/Peripherals:** 16x2 LCD, Push Buttons, LEDs, Keypad
* **Other Parts:** Resistors, Transistors
